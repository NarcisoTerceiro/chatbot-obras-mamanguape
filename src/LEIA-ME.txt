CHATBOT OBRAS: MÓDULOS ENVIADOS + PYTHON/PANDAS

O ZIP agora inclui agente.js, iaTools.js e sheets.js (baseado em sheets(8).js).
As chaves continuam no seu .env: não é necessário cadastrar outra API.

FLUXO
1. Pergunta do usuário.
2. Python entrega colunas/tipos/amostras da estrutura em cache.
3. Sua IA usa consultarComPandas para planejar filtros e operações.
4. Python acha registros no snapshot da fonte; pandas calcula se necessário.
5. IA valida a consulta/resultados: aprovar, corrigir ou esclarecer.
6. Resposta redigida pela IA após a validação. Se pedir correção, nova consulta.
Até 3 rodadas. As instruções de planejamento continuam curtas (4 linhas).

COMO INSTALAR
1. Faça backup dos arquivos antigos.
2. Copie TODOS os arquivos deste ZIP para a pasta do agente no projeto.
   Substitua agente.js, sheets.js, iaTools.js e auxiliares pandas.
   Preserve seu .env, package.json e os outros arquivos do backend/WhatsApp.
   O sheets.js do ZIP substitui o arquivo de trabalho sheets.js, não deve ficar
   com o nome sheets(8).js no projeto.
3. Use Node.js 22+ com ES Modules e Python 3.11+ com launcher py.
4. Abra instalar-pandas.bat ou rode:
   py -3 -m pip install -r requirements-pandas.txt
5. Seu projeto já usava googleapis. Se essa dependência não estiver instalada:
   npm install googleapis

Se os módulos ficam em src/, coloque os arquivos auxiliares Python, config,
schema e os scripts de teste nessa pasta também. Não substitua package.json.

CORREÇÕES NO SHEETS.JS
- Preserva números e booleanos; zero não é apagado como se fosse vazio.
- Mantém _aba e _linha da origem para identificar registros.
- Prefere linha com mais cabeçalhos reconhecidos, evitando escolher só o título.
- Cabeçalhos duplicados são recusados, evitando sobrescrita silenciosa.
- Mantém os exports getObras, limparCache, getDiagnostico,
  acharLinhaCabecalho e rowsToObjects.
- Nova opção getObras({force:true}) força a leitura em vez do cache antigo.
- getVersaoCache permite ao agente detectar sincronizações externas.
- Consulta somente leitura; preserva SHEETS_TABS e SHEETS_TABS_IGNORAR.
- Nomes de abas são escapados no range; retorno incompleto cancela a leitura.
- Leituras simultâneas compartilham uma chamada; falhas não substituem a
  versão anterior nem são usadas silenciosamente como atualização bem-sucedida.

CACHE PYTHON E ATUALIZAÇÃO
Python persistente guarda estrutura e DataFrame em memória. A leitura original
continua sendo feita por sheets.js; buscas e cálculos usam o snapshot no Python.
Não faz chamada seletiva nova ao Google para cada filtro.
Validade padrão 60 segundos, renovando na próxima pergunta após esse prazo.
No .env: PANDAS_CACHE_SECONDS=60 (>=1).
Cada pergunta fixa sua versão até acabar, mesmo com atualização simultânea.
Reinício do processo perde o cache; worker encerra após 5min de inatividade.

Quando o cache do pandas precisa renovar, o agente chama getObras({force:true})
para não ficar preso aos 3 minutos do cache antigo do Sheets.
Atualização manual:
  await responderPergunta.atualizarCache();
Ou importe atualizarCachePandas de agente.js.
Se a sincronização do seu backend chamar limparCache de sheets.js, o agente
nota a mudança de versão e renova o cache Python na próxima pergunta.
Não monitora edições da planilha continuamente; preserve seu webhook existente.

IA TOOLS
Mantido o adaptador enviado, com NVIDIA/Groq/Gemini, ordem/preferência e
metadados nativos. O catálogo já é recebido como parâmetro e suporta as
etapas consultarComPandas e validarResposta, sem chaves novas no código.
Normalmente 2 chamadas de IA por pergunta; correções podem chegar a 6.
O provedor fica fixo durante o ciclo para manter metadados compatíveis.
Testes verificam HTTP 429/fallback inicial, ferramentas inválidas, saída
truncada e preservação de metadados do Gemini. A disponibilidade real do
modelo/chave/cota da sua conta só é confirmada pelo teste real no seu computador.

TIPOS E CAPACIDADES
Campos principais: objeto, bairro, rua, status, engenheiro, empresa, aba,
tipo_registro, valor_total e valor_executado. Colunas da fonte também estão
disponíveis com prefixo original:, preservando os cabeçalhos reais.
Tipos adicionais são configurados em pandas-config.json. Exemplo:
{
 "columns": {
   "original:DATA INICIO": {"type":"date", "format":"%d/%m/%Y"},
   "original:VALOR PAGO 2026": {"type":"money", "locale":"pt_BR"}
 },
 "business_rules": []
}
Troque pelos seus cabeçalhos reais. Datas precisam de formato configurado.
Dinheiro usa Decimal/centavos. Vazio não é zero. Duplicatas não são removidas
sem definição. Percentuais precisam de escala explícita: multiplier 100 só
se 0.7551 significa 75.51%; multiplier 1 se a fonte já contém 75.51.

Consultas disponíveis: filtros AND/OR, listagem, contagem, agrupamento,
ranking, soma, média, min/max, paginação e campos derivados/diferença de datas.
Não executa código arbitrário gerado pela IA. Operação fora do executor
precisa ser esclarecida ou implementada. Classificação obra/projeto/licitação
continua baseada nas abas como no agente enviado, e precisa ser conferida na fonte.
A IA validar não garante 100%: ela ainda pode entender ou aprovar um filtro errado.

DEPLOY/ERROS
Python precisa estar no MESMO ambiente que executa Node. Instalar no Windows
não instala dentro de Docker/Render. Dockerfile.pandas é exemplo opcional
(pressupõe package-lock.json/npm start); revise antes de alterar seu deploy.
Se o Python não inicia, confira py -3 --version ou configure PYTHON_BIN no .env
com o caminho real de python.exe; instale dependências nesse mesmo Python.
Se houver erro de API, envie o diagnóstico sem chaves. Não há chaves no ZIP.
